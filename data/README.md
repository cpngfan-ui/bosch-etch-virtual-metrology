# Data

Raw and processed data are excluded from Git.

- [`PROVENANCE.md`](PROVENANCE.md) records the source DOI, license, access date, file sizes,
  checksums, and exclusions.
- [`DATA_STRUCTURE.md`](DATA_STRUCTURE.md) documents the experiment hierarchy, file schemas,
  process–metrology join, measurement lineage, target, and 81-feature table.
- `raw/` is populated by `python scripts/download_zenodo.py`.
- `processed/` is generated by `bosch-vm prepare --config
  experiments/mean_si_etch/config.yaml`.

The download script retrieves source files directly from Zenodo and verifies their published
MD5 hashes. Preparation reads those files without modifying them.
