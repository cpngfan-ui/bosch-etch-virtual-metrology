# Data Attribution

This repository uses the public dataset:

> Mudassir Ali Sayyed, Tom Seifert, Stephan Zieger, Simeon Schwarzenberg,
> Aditya Deshmukh, Micha Haase, and Jan Langer, *A Multi-Model Dataset for
> BOSCH Plasma-Etching: Optical Emission Spectra, Process Parameters, and
> Wafer Measurements for Data-Driven Plasma Modeling*.

- Zenodo record: <https://zenodo.org/records/17122442>
- DOI: <https://doi.org/10.5281/zenodo.17122442>
- Dataset license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

Raw source files are not committed to this repository. The download script
retrieves them from Zenodo and verifies their published checksums. Tables,
figures, metrics, and other derived artifacts in this repository were produced
from the cited dataset and are labeled as analytical transformations rather
than original source measurements.

See [`data/PROVENANCE.md`](data/PROVENANCE.md) for file-level provenance,
checksums, access date, exclusions, and metrology-lineage notes. Project code is
licensed separately under the [MIT License](LICENSE).
